# Student Performance Analysis

## Overview

This project analyzes factors affecting student academic performance using data analytics, visualization, and statistical methods.

The analysis explores:

- Gender-wise performance
- Parental education impact
- Lunch type impact
- Subject correlations
- Statistical significance testing

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

---

## Dataset

The dataset contains 1000 student records with:

- Gender
- Race/Ethnicity
- Parental Education
- Lunch Type
- Test Preparation
- Math Score
- Reading Score
- Writing Score

---

## Feature Engineering

Created:

- Total Score
- Average Score

for deeper analysis.

---

## Key Findings

### Gender Analysis

- Female students perform better in reading and writing.
- Male students perform slightly better in mathematics.

### Parental Education

- Students with parents holding bachelor's and master's degrees perform better.

### Lunch Type

- Students with standard lunch score higher on average.

### Subject Correlation

- Reading and writing scores show strong positive correlation.

---

## Statistical Testing

Performed independent sample t-tests to evaluate significance of observed differences.
